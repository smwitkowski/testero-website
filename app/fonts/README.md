# IBM Plex Sans

Unmodified Latin1 WOFF2 subsets from the official IBM Plex Sans 1.1.0 release:
https://github.com/IBM/plex/releases/tag/%40ibm/plex-sans%401.1.0

Archive: `ibm-plex-sans.zip`, paths `fonts/split/woff2/IBMPlexSans-*-Latin1.woff2`.
Regular (400), Medium (500), SemiBold (600), and Italic (400).
Italic is used by emphasized Markdown content. Latin1 includes basic Latin,
Western European accents and common punctuation. Other glyphs use the font fallback.

The original SIL Open Font License 1.1 is included as `OFL.txt`.
Do not modify or subset these files without checking the reserved-name terms.
