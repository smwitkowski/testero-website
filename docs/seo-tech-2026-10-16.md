## Cache evidence

Before: home/blog/post `Cache-Control: private, no-cache, no-store, max-age=0, must-revalidate`, dynamic build output.

After: home/blog/post, FAQ index/detail and pricing `Cache-Control: s-maxage=31536000`, `x-nextjs-cache: HIT`; no `Set-Cookie`, including with an invalid auth-cookie fixture. This was the initial observed policy; it was replaced in the follow-up because an external shared cache can retain HTML across deployments. No year-long browser caching was added. `/api/auth/navigation` and `/api/billing/access`: `private, no-store`. Repeated sitemap responses are equal; static lastmod is fixed at build time, not request time.
